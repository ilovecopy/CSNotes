# 十六、注解

注解=【贴标签】：给类/字段/方法贴个标签，标签带上参数，运行期/编译期通过反射读标签。

## @Transanctional

告诉 Spring：这个方法的所有数据库操作要包在同一个【全成功/全失败】的原子操作里。这个方法执行过程中任何一行抛出 RuntimeException（默认），数据库之前做过的所有 UPDATE/INSERT/DELETE 全部自动回滚；方法正常 return 的话，所有修改一次性 commit 提交。本质是 Spring AOP+ 动态代理在你的业务代码前后自动加了 begin transaction 和 commit/rollback 两句 JDBC 代码

::: danger

默认只回滚 RuntimeException/Error，Checked Exception 默认不回滚！

:::

::: tip

Spring 官方推荐：永远显示写 rollbackFor=Exception.class

@Transactional(rollbackFor=Exception.class)//任何 Exception（含 Checked）都回滚

:::

timeout 计数的开始时间

@Transactional(timeout=30) 不是整个方法从第一行到 return 不能超过 30 秒，实际是【拿到 Connection 之后，第 1 条 SQL 执行完开始算，到最后一条 SQL 执行完不能超过 30 秒】

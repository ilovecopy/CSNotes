# 十一、工具类设计规范

什么是工具类？

工具类是一组静态方法的集合，用于提供通用的、独立于业务状态的功能。

工具类应该处于叶子结点。

一般使用静态方法：通过类名调用，无需创建对象。

抽象类不能被实例化。

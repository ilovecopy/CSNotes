# 九、static 关键字

我要统计公司总共有多少个员工->总员工数不能放在每个 Employee 对象里（每个对象都会存一份会重复），应该是【整个 Employee 类共享一个计数器】：static

static 四种用法：

静态变量`private static long totalEmployees=0;`->所有 Employee 共享，JVM 内存里只有一份

静态方法`public static long getTotalEmployees(){return totalEmployees;}`->没有`this`，所以静态方法里不能访问非静态字段 id/salary（没有 this 就找不到是哪个员工的 id

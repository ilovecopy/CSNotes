# 一、多线程

## （一）为什么要有多线程？

多线程是让一个进程内的多个执行流并发地推进任务，从而更充分地利用 CPU 和 I/O 资源。

## 单线程的瓶颈在哪？

### 1.CPU 和 I/O 速度严重不匹配

CPU 执行指令是纳秒级，而一次磁盘 I/O 或网络请求是毫秒级，差了好几个数量级。单线程发起 I/O 后只能阻塞等待，这段时间 CPU 完全空闲。多线程让一个线程等 I/O 时，其他线程继续用 CPU。

## 两个并

### 并发

一台处理器上同时处理多个事件。

### 并行

多台处理器上同时处理多个事件。

## 三个程

进程、线程、管程。

用来提升程序性能的，使用多线程可以让程序充分利用 CPU 资源，提高 CPU 的使用效率，从而解决高并发带来的负载均衡问题。

优点：

1、资源得到更合理的利用

2、程序设计更加简洁

3、程序响应更快，运行效率更高

缺点：

1、需要更多的内存空间来支持多线程

2、多线程并发访问的情况可能会影响数据准确性

3、数据被多线程共享，可能会出现死锁的情况

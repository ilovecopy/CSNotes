# 二、高可用

## （一）、什么是高可用？

高可用指的是系统在面临故障时，仍能持续提供服务的能力。

| 可用性  | 年停机时间   | 俗称   |
| ------- | ------------ | ------ |
| 99%     | 约 3.65 天   | 两个 9 |
| 99.9%   | 约 8.76 小时 | 三个 9 |
| 99.99%  | 约 52.6 分钟 | 四个 9 |
| 99.999% | 约 5.26 分钟 | 五个 9 |

数字每多一个 9，成本和架构复杂度往往呈指数级上升。所以高可用不是越高越好，而是匹配业务需求——内部工具两个 9 就够，支付系统可能要四个 9 以上。

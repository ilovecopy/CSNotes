# 三、线程池

## （一）七个参数

```java
public ThreadPoolExecutor(
    int corePoolSize,                  // 4 常驻核心线程数
    int maximumPoolSize,               // 8 最大线程数
    long keepAliveTime,                // 60 超过 core 的线程空闲多久销毁
    TimeUnit unit,                     // SECONDS
    BlockingQueue<Runnable> workQueue, // 任务排队的地方
    ThreadFactory threadFactory,       // 线程怎么造
    RejectedExecutionHandler handler   // 满了怎么办
)
```

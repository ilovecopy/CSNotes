# 一、主从复制

主库写入数据，从库自动同步。

为什么需要主从复制？

| 目的     | 说明                                             |
| -------- | ------------------------------------------------ |
| 读写分离 | 写请求发到主库，读请求发到从库，主库压力因此减半 |
| 高可用   | 主库宕机后切换到从库，服务不中断                 |
| 备份     | 从库可实时创建备份，避免影响主库                 |
| 异地容灾 | 从库部署在异地，应对机房故障                     |

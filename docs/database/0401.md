# 一、为什么要有索引？

索引的本质，是用额外的存储空间和写入开销，换取查询时避免全表扫描。

## （一）没有索引会怎样

假设一张 users 表有 10 万行，你要查 where id=500000，没有索引，MySQL 只能从第一行开始逐行对比，这叫全表扫描。

## （二）索引分类

主键索引：叶子节点存放的是完整的行数据，找到索引就找到了整行。

二级索引：叶子节点存放的是索引列的值 + 主键 ID，不存完整行。找到索引只拿到主键，要整行还得再查一次。

主键索引就是表本身。

所以一张表只能有一个主键索引：因为数据只能按一种顺序无力阻止一次。

主键不宜过长，因为每个二级索引都要存一份主键。

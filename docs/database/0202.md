# 二、EXPLAIN 执行计划

什么是执行计划，执行计划就是能看到 SQL 执行的底层细节。

执行计划分为根节点和子节点。

看到 TABLE FULL SCAN 就要考虑建索引。

根节点行数越少越优

OB 算子：



出现层级：页

`TABLE GET` ：主键等值点查。

`TABLE SCAN`：走索引的范围扫

`TABLE FULL SCAN`：无索引列过滤，逐行扫

`SUBPLAN SCAN`：内部 SQL 产出行数



出现层级：中层

`HASH GROUP BY`：group by 分组聚合

`HAVING FILTER`：聚合完成后按聚合列过滤

出现层级：上层

`SORT`：ORDER BY 内存排序，行数不变

出现层级：根

`LIMIT`：LIMIT+OFFSET 裁剪输出

`UNION ALL CONCAT`:每段行数相加

`NESTED LOOP LEFT JOIN`
